### Краткое описание источников и выводы по обзору литературы

Литература по теме делится на три группы. Первая — работы по нейросетевому поиску FRB на западных инструментах (GBT, Arecibo, CHIME). Все они опираются на данные с тысячами узких каналов, которые можно представить как 2D-изображения «частота–время», и используют 2D-свёрточные сети (FETCH, ResNet, multi-input CNN). Вторая — аппаратные работы РАТАН-600, показывающие, что инструмент располагает лишь 4 широкими каналами по 150 МГц, что исключает прямое применение 2D-подходов. Третья — работа Kudryavtsev et al. (2026), которая закрывает разрыв: авторы адаптируют EfficientNet к 1D-данным (4 канала), генерируют синтетические FRB для обучения и добавляют каскадную схему подавления ложных срабатываний. Вывод: прямая экстраполяция западных ML-решений на РАТАН-600 невозможна из-за формата данных; работа РАТАН-600 занимает уникальную нишу, предлагая 1D-архитектуру, которая может быть полезна и для других инструментов с малым числом широких каналов.

### Таблица сравнения

**Почему выбраны эти критерии:** Ключевое ограничение работы — формат входных данных (4 широких канала РАТАН-600 против тысяч узких каналов у западных инструментов), поэтому главный критерий — размерность входных данных и тип свёрток. Второй критерий — архитектура и вычислительная эффективность: EfficientNet выбран как более лёгкая и быстрая альтернатива ResNet. Третий критерий — механизм подавления ложных срабатываний, критичный при обработке больших потоков данных. Четвёртый — открытость кода, важная для воспроизводимости.

### Выводы по сравнению

Из существующих решений можно использовать **идею генерации синтетических FRB для обучения** (применена и в FETCH, и в работе РАТАН-600) и **каскадную схему верификации кандидатов**, которая в работе РАТАН-600 доводит долю ложных срабатываний до порядка 0.0005%. Также полезен подход **переноса обучения (transfer learning)**, использованный в FETCH, хотя для 1D-данных РАТАН-600 он требует адаптации.

Ограничения, которые устраняются: существующие модели (FETCH, Connor & van Leeuwen) требуют 2D-представления данных, что невозможно при 4 каналах; прямое применение 2D-свёрток к таким данным вычислительно неоправданно и теряет смысл второго измерения. Наше решение заменяет 2D-свёртки на 1D, снижая число параметров и вычислительную сложность при сохранении точности.

## 4. Итоги

**Итоговая тема ВКР:** Разработка и исследование одномерной свёрточной нейронной сети для поиска быстрых радиовсплесков в многоканальных данных РАТАН-600.

**УДК для тезиса:** 524.7-77 + 004.032.26 (рекомендуется уточнить с научным руководителем; базовый индекс для FRB и астрофизических методов — 524.7, для нейросетевых методов в астрономии — 004.032.26)

**Ключевые слова:** быстрые радиовсплески, FRB, нейронные сети, свёрточные сети, EfficientNet, 1D-CNN, РАТАН-600, классификация временных рядов, радиоастрономия.

### Актуальность исследования

Быстрые радиовсплески — одно из самых активно изучаемых явлений в современной радиоастрономии, однако их физическая природа до сих пор не установлена, а поток кандидатов растёт быстрее, чем возможности их ручной проверки. На западных инструментах (GBT, CHIME, ASKAP) проблема решается нейросетями на 2D-спектрограммах с тысячами каналов. Однако РАТАН-600 располагает лишь четырьмя широкими каналами, что делает западные архитектуры неприменимыми напрямую. Работа Kudryavtsev et al. (2026) показала принципиальную возможность 1D-подхода, но остаётся открытым вопрос оптимизации архитектуры и оценки её устойчивости на реальных данных обзоров. Исследование актуально, поскольку предлагает решение для инструментов с ограниченным числом каналов, которые пока выпадают из мировой практики ML-поиска FRB.

### Цель исследования

Разработать и оценить эффективность одномерной свёрточной нейронной сети для автоматического поиска быстрых радиовсплесков в 4-канальных данных РАТАН-600, обеспечивающей низкий уровень ложных срабатываний при сохранении чувствительности к слабым сигналам.

### Задачи исследования

1. Провести обзор существующих ML-подходов к поиску FRB и обосновать выбор 1D-архитектуры для данных с малым числом каналов.
2. Реализовать процедуру генерации синтетических FRB, соответствующих параметрам радиометров РАТАН-600 (4 канала × 150 МГц, временное разрешение 60–490 мкс).
3. Адаптировать архитектуру EfficientNetV2 к 1D-данным (EfficientNet1d-XS) и обучить модель на синтетической выборке.
4. Реализовать каскадную схему из двух сетей для подавления ложных срабатываний и оценить её эффективность.
5. Проверить модель на реальных записях РАТАН-600 (включая гигантский импульс Крабовидной туманности как контрольный сигнал) и оценить полноту и точность.

### Датасеты и сервисы

**Собственные данные РАТАН-600:** записи обзоров Западного сектора РАТАН-600 с 2017 г., формат — 4-канальные временные ряды в диапазоне 4.4–5 ГГц с дискретизацией 60–490 мкс. 

**Синтетические FRB:** генерируются по описанной в статье процедуре; код генератора доступен на GitHub вместе с кодом архитектуры. Необходимы для формирования обучающей выборки, поскольку реальных подтверждённых FRB в 4-канальном формате РАТАН-600 недостаточно.

**Открытые датасеты для валидации (опционально):** данные GBT/CHIME в 2D-формате могут использоваться для проверки общих свойств модели после преобразования к 1D, но требуют предварительной обработки; доступность определяется политикой соответствующих обсерваторий.

**Сервисы:** PyTorch (фреймворк для реализации сети), GitHub (хостинг кода), вычислительные ресурсы САО РАН или локальный GPU-кластер для обучения.
