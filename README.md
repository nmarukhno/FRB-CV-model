## Проект

**Тема: Разработка модели для машинного анализа данных телескопа РАТАН 600 по поиску быстрых радиовсплесков(FRB)**

**Участники: Марухно Никита Андреевич, Кудрявцев Дмитрий Олегович**

**Проблема: Уменьшение количества ложноположительных срабатываний модели Efficient Net family of models (Tan and Le, 2019, 2021)** 

**Ожидаемый результат: Улучшение поиска FRB в данных радиотелескопа РАТАН 600, которое поможет увеличить базу исследований данного астрономического события.**
